# PRD — 훌메이트 (소규모 교회용 화이트라벨 멀티테넌트 PWA)

> **이 파일이 PRD의 정본(SSOT)입니다.** 기획자가 직접 수정하거나 `/pd-prd`로 갱신합니다.
> `config/prd.js`는 이 문서에서 동기화되는 렌더용 미러입니다.

- **version**: 1.1.4 · **updated**: 2026-10-04 · **status**: 기획 v1.1.4(적대검수 H1~H5·M1·M3·M4 반영) · **surface**: 모바일(교인앱·공개홈) · PC웹(관리자·슈퍼)

---

## ① 배경
소규모 교회(예장통합 100명 이하 72%)는 재정·인력난으로 자체 앱·홈페이지를 갖기 어렵고, 기존 공용 입주형 앱은 교회 고유 브랜드를 담지 못한다. 훌메이트는 한 코드베이스(화이트라벨 멀티테넌트)로 교회마다 독립 브랜드의 교인앱·공개홈·관리자콘솔을 30분 내 발행하고 유지비를 최소화한다. 은성교회를 1호 파일럿으로 검증한다.

## ② 목표
- 교회별 독립 브랜드 앱(교인앱·공개홈)을 코드 복제 없이 설정값만으로 발행
- 목회자가 콘솔에서 설교·공지·성도·공개홈을 직접 관리(개발자 없이 운영)
- 개인정보보호(PIPA)를 기본 내장 — "가입만 해도 법 준수"
- 파일럿(은성) 기준 공개홈·교인앱 운영 품질 달성

## ③ 사용자
- **교인(성도)** — 설교·공지·헌금안내를 확인하고, 내 영수증·출석·개인정보를 스스로 관리
- **목회자/관리자** — 개발자 없이 설교·성도·공지·공개홈을 직접 관리하고 현황 파악
- **방문자(새가족)** — 공개 홈에서 예배 시간·오시는 길·분위기 파악
- **플랫폼 운영자** — 여러 교회(테넌트)를 안전하게 운영·분리·심사·과금

## ④ 범위
**포함**
- 교인앱(모바일 PWA): 홈·설교·헌금안내·마이·커뮤니티·아나바다·교회학교·주보·성도매장·알림·설정·검색·출석(QR/온라인)·영수증 조회·개인정보 권리요청·약관/처리방침
- 공개홈(모바일): 환영/말씀/공동체/콘텐츠형 4템플릿·예배안내·교회소개·교역자·위치·설교·새가족·소식·법적 고지
- 관리자콘솔(PC웹): 대시보드·성도관리·출석·설교·공지·재정·문자지갑·PIPA·홈페이지·공개홈 콘텐츠 관리·UGC 모더레이션·로그인/계정
- 슈퍼관리자(PC웹): 테넌트·심사·구독/플랜·도메인·감사로그·로그인

**제외(차기)**: 헌금 실 PG 결제(안내전용) · 정기구독(교인) · 다국어 · 실시간 채팅상담 · 성도 1:1 메시지

## ⑥ 제약·가정·의존성
- **제약**: 멀티테넌트 격리(tenant 스코프 강제) · PIPA 내장(민감정보 전용권한·암호화·마스킹·동의·14세 미만 법정대리인·권리행사) · 정직성(미확보 콘텐츠="교회 확인 후 게재") · 되돌리기 어려운 쓰기(영수증·대량발송·발행·승인)는 멱등키·확인·취소·감사로그
- **가정**: 교인=모바일·관리자=PC웹 · 설교=유튜브 URL · 비회원=slug/도메인 공개홈, 교인=로그인 후 앱
- **의존성**: platform-db churchhub(멀티테넌트·RLS) · 화이트라벨 엔진 · 외부(유튜브·FCM/Web Push·문자발송사·DNS·차기 PG)

## ⑦ 비기능 요구사항(NFR)
- **접근성(필수 게이트)**: WCAG 2.1 AA. 고령 교인 대상 — 본문 16px+·글자크기 조절·명암 대비 4.5:1·터치 타깃 44px+·스크린리더 레이블·폼 에러 음성안내
- **PWA**: 서비스워커 오프라인 캐싱·앱 설치 유도·업데이트 알림·오프라인 fallback. iOS Safari PWA 푸시 제약 고지
- **푸시**: Web Push(FCM)·권한요청 UX·수신동의 연계·야간발송 제한(21~08시)·카테고리별 수신설정
- **보안**: JWT·HTTPS 전용·민감정보 AES 암호화·비번정책(8자+)·감사로그 3년 보존·로그인 실패 제한
- **성능**: 주일 트래픽 스파이크 대비·홈 <1s·설교목록 <2s·CDN·이미지 최적화
- **가용성**: 99.5%·일 백업·DR. 지원 브라우저: 최신 Chrome/Safari/Samsung Internet

## ⑧ 권한 모델(RBAC) — role(직분) × permission(기능) 2축
**역할**: member(일반 교인) · staff(교역자·직원) · pastor(담임목사) · admin(교회 관리자) · super(플랫폼 운영자)
**권한**: finance.read/write · pii.read · member.approve · message.send · homepage.edit · content.edit · moderate

| 주체 | 할 수 있는 것 |
|---|---|
| member | 본인 정보·영수증 조회·권리요청·출석·알림설정·커뮤니티 작성 |
| staff | 설교·공지·공개홈 콘텐츠 작성(content.edit) |
| pastor | staff 전체 + 성도 조회 + 가입 승인(member.approve) |
| admin | 성도관리·승인·권한 위임·홈페이지(homepage.edit)·공지·모더레이션 |
| admin + finance | 재정·영수증 발급(finance.read/write) |
| admin + privacy | 민감정보 열람(pii.read)·권리요청 처리 |
| super | 테넌트 발행·심사·구독·도메인·감사로그(교차테넌트 — 전 접근 감사기록) |

> pii.read·finance·message.send는 명시 위임 권한 필요. 모든 교차테넌트 접근은 audit 로그.

## ⑨ 멀티테넌트 격리 계약
- **격리**: 모든 조회·쓰기는 tenantId 스코프 강제. DB Row-Level Security(RLS) + 앱레벨 필터 이중 방어
- **식별**: app/admin API는 JWT의 tenantId claim으로 판별(path 노출 X). 공개홈(site)은 slug(`?tenant=`) 또는 custom domain
- **교차접근**: 슈퍼관리자만 가능, 모든 접근은 감사로그에 memberId·대상·시각 기록
- **오프보딩**: 교회 해지 시 데이터 반출(export) 후 파기(PIPA·데이터 주권). 유예 30일

## ⑩ 대체재·지불의사(WTP)
| 대체재 | 비용 | 한계 |
|---|---|---|
| 네이버 밴드 | 무료 | 교회 전용 아님·브랜드 없음·설교/헌금/교적/영수증 미지원·광고 |
| 카카오톡 채널 | 무료 | 공지 일방향·커뮤니티/관리/교적 없음 |
| 유튜브 | 무료 | 설교 송출만·공동체/관리/개인정보 전무 |
| 공용 입주형 교회앱 | 유료 | 교회 고유 브랜드 없음·커스터마이즈 제한·PIPA 부담 전가 |

**차별화**: 독립 브랜드 앱(화이트라벨) · PIPA 기본 내장 · 30분 발행·무개발 운영 · 교적/출석/영수증/헌금/공개홈 통합
**WTP**: 월 3~5만(개교회 예산 내). 전환 트리거=개인정보보호법 부담·독립 브랜드 필요·공용앱 불만. 은성 파일럿 유료전환 의사로 1차 검증.
**리스크**: 무료 대체재(밴드) 대비 WTP가 핵심 하방 → 파일럿 WTP 증거 확보 전 대규모 투입 금지(비대칭 하방 방어).

## ⚠️ ⑮ J-게이트 (규제·결제·대외발송 — 기획자 결재 필수)

1. **PIPA**: 민감정보(주민번호)·14세 미만 법정대리인 동의·처리방침/동의서·처리위탁 고지 — 법무 검토
2. **전자기부금영수증(세무)**: 발급 정확성·취소·보존 — 되돌리기 어려움
3. **대외 발송(문자/푸시)**: 수신동의·옵트아웃·야간발송 제한
4. **헌금 계좌 안내 / 향후 PG**: 유사수신·전자금융 규제 경계
5. **이단심사 게이트**: 종교 차별 소지 — 심사 기준·주체·이의절차 사전 합의
