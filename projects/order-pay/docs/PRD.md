# PRD — 간편결제 데모

> 이 파일이 PRD 정본(SSOT). 변경 시 버전을 올리고 이력에 남깁니다. `config/prd.js`는 렌더용 미러입니다.

- **version**: 0.1.0 · **updated**: 2026-10-02 · **status**: 데모 · **surface**: 모바일

## ① 배경
기존 결제는 회원가입·로그인 단계에서 이탈이 크다. 비회원이 상품 선택 후 최소 단계로 결제를 끝내게 해 전환율을 높인다.

## ② 목표
- 비회원도 상품 선택 후 3탭 안에 결제 완료
- 결제 실패 시 1탭으로 재시도
- 결제 완료율 70% 이상

## ③ 사용자
- **구매자(비회원)** — "급하게 선물할 때, 가입 없이 빠르게 결제하고 싶다, 그래서 약속을 지킨다"

## ④ 범위
**포함**: 상품 목록 · 상품 상세 · 결제 · 완료 · 실패/재시도
**제외**: 회원가입 · 정기구독 · 다국어 · 환불

## ⑤ 성공지표
| 지표 | 목표 |
|---|---|
| 결제 완료율 | 70% 이상 |
| 결제 평균 소요 | 30초 이내 |

## ⑥ 제약·가정·의존성
- 제약: PG는 토스페이먼츠 고정 · 비회원 게스트 토큰
- 가정: 사용자는 구매 의사가 있는 상태로 진입
- 의존성: 상품 카탈로그 API(기존) · 결제 PG(토스페이먼츠)

## ⑦ 릴리스
- MVP (2026-Q4): 상품 목록·상세·결제·완료·실패

## 요구사항
| reqId | 내용 |
|---|---|
| REQ-001 | 사용자는 상품 목록을 보고 하나를 선택할 수 있다 |
| REQ-002 | 사용자는 상품 상세를 보고 결제로 진입할 수 있다 |
| REQ-003 | 사용자는 결제수단을 선택해 결제할 수 있다 |
| REQ-004 | 결제 성공 시 완료 화면을, 실패 시 재시도 화면을 본다 |

## 핵심 워크플로
**간편결제** (모바일): 상품목록 → 상품상세 → 결제 →(결제 성공 여부)→ 완료 / 실패
