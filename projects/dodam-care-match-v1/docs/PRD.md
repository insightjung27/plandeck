## ① 배경
장애아동 가정은 믿을 만한 치료·돌봄 서비스를 찾기 어렵다. 정보가 흩어져 있고 검증이 없으며 예약도 번거롭다.
도담은 "일상 포용(Everyday Inclusion)" 미션 아래, **검증된 제공자와 가정을 중개**해 첫 연결의 마찰을 없앤다.
본 PRD는 보호자 앱의 **돌봄·치료 매칭·예약·이용 관리** 전 과정과, 이를 운영하는 **운영자 콘솔**(제공자 심사·예약 관리)을 다룬다.

## ② 목표
- 보호자가 조건(지역·장애유형·서비스종류)으로 검증된 제공자를 찾아 **3단계 안에 예약 신청**
- 제공자 **검증 배지·후기**로 신뢰 기반 선택
- 예약 **상태(승인대기→확정→완료)를 추적**하고, 이용 후 **후기**로 생태계 신뢰 축적
- 운영자가 **제공자 심사**로 품질을 보증하고 **예약을 중재**
- 첫 예약 신청까지 **5분 이내**, 예약 신청 완료율 **60% 이상**

## ③ 사용자
- **보호자(장애아동 부모)** — "아이에게 맞는 치료·돌봄이 급할 때, 검증된 제공자를 빠르게 찾아 예약하고, 진행 상태를 확인하고 싶다"
- **운영자(도담 플랫폼)** — "제공자를 심사해 품질을 보증하고, 예약 현황을 모니터링하며 분쟁을 중재하고 싶다"
- (제공자 기업/전문가는 별도 앱 — 본 범위 밖)

## ④ 범위
**포함(보호자 앱)**: 로그인·회원가입 · 아동 프로필 등록/관리 · 서비스 홈/탐색 · 검색·필터 · 제공자 상세 · 예약 신청(아동·일정·동의) · 예약 확인 · 신청 완료 · 예약 내역·상태 추적 · 예약 상세·취소 · 후기 작성 · 마이
**포함(운영자 콘솔)**: 운영 대시보드 · 제공자 심사(승인/반려) · 예약 관리(모니터링·중재) · 태블릿(가로/세로) 대응
**제외(Out of Scope, 차기)**: 제공자 전용 앱 · 정산·수수료 · 실시간 채팅 · 인클루시브 매장 지도(별도 트랙) · 보험·바우처 연동 · 결제

## ⑥ 제약·가정·의존성
- **제약**: 검증 완료 제공자만 노출 · 아동 민감정보 최소수집·동의 기반 · 개인정보보호법 준수
- **가정**: 보호자는 로그인 상태, 아동 프로필 1개 이상 등록 후 예약(미등록 시 등록 유도)
- **의존성**: 제공자 검증·심사(운영자 콘솔) · 아동 프로필·계정 · 알림(예약 상태 푸시)

## 핵심 워크플로
- **W1. 매칭·예약** (모바일): 홈 → 검색결과 → 제공자 상세 → 예약 신청 → 예약 확인 →(신청 성공 여부)→ 신청 완료
- **W2. 가입·아동등록** (모바일): 로그인 → 회원가입/아동 프로필 등록 → 마이
- **W3. 예약 추적·후기** (모바일): 예약 내역 → 예약 상세(상태 추적·취소) / 완료 → 후기 작성
- **W4. 운영 심사·예약관리** (PC웹): 운영 대시보드 → 제공자 심사(승인/반려) · 예약 관리(모니터링·중재)

## ✅ 해소된 설계 결정 (구 미결질문 → v1.0 확정)
- **아동 프로필 미등록 진입** → 예약 진입 시 미등록이면 **아동 프로필 등록 화면으로 유도**(SCR-CHILD-001). 등록 후 예약 재개.
- **예약 "신청→승인" 모델** → **승인 대기형**(비동기)으로 확정. 신청 즉시 '승인대기', 제공자 승인 시 '확정'. 상태는 예약 내역(SCR-BOOKINGS-001)에서 추적.
- **결제 시점** → 본 릴리스 **범위 밖(차기)**. 예약은 신청·승인까지만.
- **민감정보 수집 범위** → 아동 발달/장애유형은 **선택 입력 + 명시 동의** 기반. 수집 최소화, 동의 없으면 예약 불가(개인정보보호법 준수).
