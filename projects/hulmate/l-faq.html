자주 묻는 질문
Web·PWA 차이, 교회 전용 링크(church_id 자동 매핑), Web Push, 도메인, 가격, 데이터 소유에 대해 자주 묻는 질문을 모았습니다. 질문을 누르면 답변이 펼쳐집니다. 찾는 답이 없으면 아래 문의하기로 남겨주세요.
자주 묻는 질문
현재 도입 범위는 공개 Web과 교인용 PWA입니다. Web은 누구나 접속하는 공개 교회 홈페이지이고, PWA는 교인이 로그인해 설교·주보·공지를 받는 앱형 화면입니다. 네이티브 앱(APP 상품)은 차기 단계로 준비 중입니다.
PWA는 별도 앱스토어 설치 없이 교회 전용 링크에 접속한 뒤 홈화면에 추가하면 앱처럼 쓰는 방식입니다. 교인용 화면은 홈·설교·주보·공지·마이 5개 메뉴로 제공됩니다.
교회 검색 과정은 없습니다. 개설 승인 시 발급되는 교회 전용 링크로 교인이 바로 접속하며, 접속 시 church_id가 자동으로 매핑됩니다.
공지·설교 소식은 Web Push로 전달됩니다. 교인이 기기·브라우저에서 알림 수신에 동의한 경우에 발송되며, 수신 조건은 기기·브라우저 설정에 따릅니다. 네이티브 푸시는 APP 상품(차기)에서 준비 중입니다.
개설 승인 시 교회 전용 링크가 기본 제공됩니다. 자체 도메인 연결 여부·방식은 교회 확인 후 안내드립니다(준비 중).
요금은 초기등록비 + 월 이용료 구조이며, 구체 금액은 교회 확인 후 안내드립니다(현재 미확정). 정확한 안내는 교회 개설 신청 또는 문의를 통해 드립니다.
교회별 데이터는 서로 완전히 분리되어 저장·관리됩니다(Tenant 격리). 한 교회의 데이터가 다른 교회 화면에 노출되지 않으며, 교회 데이터의 소유권은 교회에 있습니다.
모든 화면은 단일 디자인 시스템으로 통일됩니다. 교회명·로고·색상 등 브랜딩은 관리자 설정 Wizard에서 반영하며, 레이아웃·구성은 공통으로 유지되어 품질이 일관됩니다.
