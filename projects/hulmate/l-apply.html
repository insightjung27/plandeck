slug 중복 확인사용 가능이미 사용 중형식 오류(영문 소문자·숫자·하이픈)
희망 주소(slug)는 중복 확인 후 확정됩니다. 이미 사용 중이면 "이미 사용 중인 주소예요. 다른 slug를 입력해주세요"라고 안내되며 다른 값을 입력해야 합니다. 확정된 slug가 교회 전용 접속 주소가 됩니다.
요금제 선택
WEB 상품 이용료미확정
WEB+APP 이용료미확정
요금은 초기등록비 + 월 이용료 구조이며, 구체 금액은 교회 확인 후 안내드립니다(현재 미확정). 네이티브 앱(APP 상품)은 차기 단계로 준비 중이며, 현재 도입 범위는 공개 Web과 교인용 PWA입니다.

제출 전 확인
제출하면 개설 신청(OnboardingApplication)이 생성되어 슈퍼 운영자 검토 큐로 접수됩니다. 제출 전 확인 모달이 표시되며, 재클릭해도 중복 생성되지 않습니다(멱등 처리 — "이미 접수된 신청이에요"). 접수 성공 시 "신청이 접수됐어요. 슈퍼 운영자 승인을 기다려주세요"라고 안내됩니다.
개설 신청 시 이용약관 · 개인정보 처리방침에 동의하는 것으로 간주됩니다. 전문은 약관 화면에서 확인하실 수 있어요.
개설 신청을 접수할까요?
입력하신 교회정보와 선택한 요금제를 확인한 뒤 개설 신청(OnboardingApplication)으로 접수합니다. 재클릭해도 중복 생성되지 않아요(멱등 처리 — 이미 접수된 경우 "이미 접수된 신청이에요"). 접수가 완료되면 접수완료 화면으로 이동하며, 슈퍼 운영자 승인을 기다리게 됩니다.
