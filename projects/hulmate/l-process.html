도입 절차 — 4단계
개설 신청부터 오픈까지 4단계로 끝납니다. 복잡한 개발 없이 설정만으로 교회 전용 Web·교인 PWA가 열립니다. 교회 검색 과정은 없고, 승인 시 발급되는 전용 주소로 교인이 바로 접속합니다(church_id 자동 매핑).

단계별로 무엇을 하나요
1. 개설 신청
교회명·연락처 등 기본 정보를 입력해 신청합니다.
2. 검토·승인 영업일 1~2일
담당자가 신청 내용을 확인한 뒤 승인합니다. 보통 영업일 기준 1~2일 안에 처리됩니다.
3. 초기 설정
승인 즉시 전용 Tenant가 자동 생성됩니다. 관리자 설정 Wizard로 로고·대표색·설교·주보·공지를 채웁니다.
4. 오픈
교회 전용 주소로 교인이 바로 접속합니다. 공지·설교는 Web Push로 전달됩니다.
승인 후, 설정만으로 오픈
Tenant 자동 생성 · 관리자 설정 Wizard 8STEP
승인되면 교회 전용 Tenant가 자동으로 만들어지고, 관리자는 교회명·로고·색상·설교·주보·공지를 설정 Wizard 8단계로 채우기만 하면 서비스가 열립니다. 모든 화면은 단일 디자인 시스템으로 통일되며, 교회별 데이터는 서로 완전히 분리됩니다(테넌트 격리).

도입 전 알아두기
· 요금은 초기 등록비 + 월 이용료 구조이며, 금액은 미표시입니다(교회 확인 후 안내).
· 교인용 PWA는 홈·설교·주보·공지·마이 5개 메뉴로 제공되고, 공지·설교 소식은 Web Push로 전달됩니다.
· 네이티브 앱(APP 상품)은 필요한 교회만 선택하는 옵션이며, 현재 기본 도입 범위는 공개 Web과 교인용 PWA입니다.
