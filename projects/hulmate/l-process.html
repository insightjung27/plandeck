Tenant 자동 생성 · 관리자 설정 Wizard 8STEP
슈퍼 관리자가 개설 신청을 승인하면 교회 전용 Tenant가 자동으로 생성됩니다. 관리자는 교회명·로고·색상·도메인과 설교·주보·공지 등을 8단계 설정 Wizard로 채워 넣기만 하면 서비스가 열립니다. 모든 화면은 단일 디자인 시스템으로 통일되며, 교회별 데이터는 서로 완전히 분리됩니다(Tenant 격리).
도입 전 알아두기
· 요금은 초기등록비 + 월 이용료 구조이며, 구체 금액은 교회 확인 후 안내드립니다(현재 미확정).
· 오픈 시 교인용 PWA는 홈·설교·주보·공지·마이 5개 메뉴로 제공되고, 공지·설교 소식은 Web Push로 전달됩니다.
· 네이티브 앱(APP 상품)은 차기 단계로 준비 중이며, 현재 도입 범위는 공개 Web과 교인용 PWA입니다.
