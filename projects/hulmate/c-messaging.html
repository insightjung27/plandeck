즉시예약
차기부서·새가족 등 세그먼트 발송과 문자(SMS) 채널은 교적 기능 재개 후 제공됩니다. 현재 V1은 전체 교인 대상 Web Push만 지원해요.
Web Push는 수신동의(구독)한 교인에게만 전달되고, 수신거부(동의 철회) 교인은 자동 제외됩니다(PIPA).
대량 발송 — 되돌릴 수 없음
전체 교인 128명에게 Web Push를 발송합니다. 발송 후 취소할 수 없어요(예약 발송만 발송 전 취소 가능). 수신거부 교인은 자동 제외되고, Idempotency-Key로 중복 발송을 방지합니다.
