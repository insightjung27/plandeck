# 훌메이트 — PRD (제품요구정의서)

> 정본. `config/prd.js`는 이 문서를 렌더용으로 미러한다. 변경 시 버전을 올린다(현재 v0.1.0).

소규모 교회용 **화이트라벨 멀티테넌트 PWA**. 한 코드베이스로 교회마다 독립 브랜드의 **교인앱·공개홈·관리자콘솔**을 발행한다. 은성교회 1호 파일럿.

## ① 배경
소규모 교회(예장통합 100명 이하 72%)는 재정·인력난으로 자체 앱·홈페이지를 갖기 어렵고, 공용 입주형 앱은 교회 고유 브랜드를 담지 못한다. 훌메이트는 설정값만으로 교회별 독립 브랜드 앱을 30분 내 발행하고 유지비를 최소화한다.

## ② 목표
- 교회별 독립 브랜드 앱을 코드 복제 없이 설정값만으로 발행
- 목회자가 콘솔에서 설교·공지·성도를 직접 관리(개발자 없이 운영)
- 개인정보보호(PIPA) 기본 내장 — "가입만 해도 법 준수"
- 파일럿(은성) 기준 공개홈·교인앱 운영 품질 달성

## ③ 사용자
- **교인(성도)** — 우리 교회 앱에서 설교·공지·헌금안내 확인
- **목회자/관리자** — 개발자 없이 설교·성도·공지 관리, 현황 보고
- **방문자(새가족)** — 공개 홈에서 예배 시간·오시는 길 확인
- **플랫폼 운영자** — 여러 교회(테넌트)를 안전하게 분리·운영

## ④ 범위
**포함**: 교인앱(홈·설교·헌금안내·마이), 공개홈(환영형 홈·예배안내), 관리자콘솔(대시보드·성도관리), 화이트라벨(브랜드·기능 On/Off·템플릿)
**제외**: 헌금 실 PG 결제(안내전용), SMS(푸시 대체), 교적 프론트(은성 OFF)

## ⑤ 성공지표
- 파일럿 공개홈·교인앱 운영 품질 — 은성 실데이터 실렌더 합격
- SOM(3년) — 1,000교회 · 구독 ARR 4.8억(목표)
- 발행 소요 — 교회 1곳 30분 내

## ⑥ 제약·가정·의존성
- 멀티테넌트 격리(모든 조회·쓰기 교회 스코프), PIPA 내장, 정직성(미확보 콘텐츠=교회 확인 후 게재)
- 설교 영상=유튜브 연동 / platform-db churchhub 스키마·화이트라벨 엔진 의존

## ⑦ 릴리스
- **Pilot(은성 1호)**: 공개홈·교인앱·관리자(대시보드·성도관리)
- **Phase 0 MVP**: 출석·전자기부금영수증·문자지갑·PIPA
