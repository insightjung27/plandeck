PWA 설치 안내
우리 교회 앱처럼 이용하세요
홈 화면에 추가하면 아이콘 한 번으로 바로 열 수 있어요. 설치 앱은 교회 로고·교회명으로 추가되고, 모든 화면은 단일 디자인 시스템으로 통일됩니다. 네이티브 앱(스토어 설치)은 차기 제공 예정입니다.
Android · Chrome
홈 화면에 설치
설치 버튼은 브라우저가 설치 가능 시점(beforeinstallprompt)을 알릴 때 활성화돼요. 탭하면 브라우저 기본 설치 프롬프트가 뜹니다. 이미 설치된 경우에는 "이미 홈 화면에 설치되어 있어요"로 안내돼요.
iPhone · Safari (iOS 16.4+)
iPhone에서는 설치형 버튼이 제공되지 않아요. 아래 수동 단계로 추가하세요.
1
공유 버튼 탭
2
홈 화면에 추가
3
추가 확인
공유 버튼을 눌러 '홈 화면에 추가'를 선택하세요. iOS 16.4 미만이나 지원하지 않는 브라우저에서는 설치와 알림이 제한돼요.
설치 아이콘 미리보기
○○교회
홈 화면에 교회 로고·교회명으로 추가됩니다(PwaConfig). 실제 아이콘·시작화면은 교회 설정 확인 후 게재.
알림(Web Push)
iPhone에서는 홈 화면에 설치한 경우에만 Web Push 알림을 받을 수 있어요(iOS 16.4+). Android·데스크톱은 설치 없이도 알림을 받을 수 있습니다.
