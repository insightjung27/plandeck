H-우리교회 / 기본 포함 기능
기본으로 들어 있어요
개설하면 아래 기능이 모든 교회의 Web·교인 PWA에 기본으로 들어갑니다. 따로 고르거나 추가 개발할 필요 없이, 설정만으로 바로 씁니다. 교회마다 데이터는 서로 분리됩니다(테넌트 격리).
기본 포함 기능 12가지

주보 PDF
공지·상단 고정
교회별 회원가입
알림·예약 발송
로고·대표색
홈화면 스타일

글자 크기 조절
자체 도메인(옵션)
브라우저로 바로 받는 알림
공지·설교가 올라오면 교인 기기로 바로 전송
안드로이드·데스크톱 브라우저에서는 별도 설치 없이 Web Push를 바로 받습니다. 새 공지·설교가 게시되면 교인 기기로 알림이 전송됩니다.
iOS는 16.4 이상에서 홈 화면에 설치한 PWA에 한해 수신됩니다. 네이티브 앱(APP) 푸시는 옵션 상품입니다.
