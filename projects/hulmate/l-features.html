교회 공개홈
방문자용 반응형 웹 — 교회 소개·설교·주보·소식·오시는 길
교인 PWA
로그인 교인용 — 홈·설교·주보·공지·마이 5개 메뉴, 홈 화면 설치형 웹앱
관리자 콘솔
교역자·간사용 — 회원 승인·설교/공지 게시·알림 발송(교회별 데이터 격리)
Web Push 알림
공지·설교 게시 시 즉시 발송. iOS는 설치형 PWA 조건부(아래 참고)
개설 Wizard
교회명·연락처 입력 → church_id 자동 발급 → 홈·앱 자동 생성(교회 검색 불필요)
Web Push 알림 — 수신 조건
브라우저로 바로 받는 알림
안드로이드·데스크톱 브라우저에서는 별도 설치 없이 Web Push를 바로 수신합니다. 새 공지·설교가 게시되면 교인 기기로 알림이 전송됩니다.
iOS는 16.4 이상에서 홈 화면에 설치한 PWA에 한해 수신됩니다. 네이티브 앱(App Store/Play) 푸시는 차기 과제입니다.
