주보·설교·공지, 한 번 올리면 끝.

주보 PDF 한 장, 설교 영상 링크 하나, 공지 한 줄만 올리면 교회 공개 홈페이지와 교인 앱에 동시에 반영됩니다. 홈페이지 제작도, 앱 개발도, 매년 드는 앱 비용도 필요 없습니다.

개발자 없이
홈페이지·앱 제작 지식이 없어도 관리자 콘솔에서 설정만으로 시작합니다.
앱 비용 없이
앱스토어·플레이스토어 등록·심사·연간 비용 없이 설치형 Web(PWA)으로 시작합니다.
1~2일 개설
신청 후 영업일 1~2일 내 검토·승인, 승인되면 바로 설정하고 오픈합니다.
입력하면 바로 보입니다 — 실시간 미리보기
교회 이름과 대표 색을 입력하면, 공개 홈페이지(PC)와 교인 앱(휴대폰)이 실제로 어떻게 보이는지 그 자리에서 나타납니다. 와이어프레임에서는 입력폼과 미리보기 틀로 표현합니다.
예: 은혜교회
남색 / 자주 / 초록 중 선택
입력한 이름으로 개설 신청
공개 홈페이지 (PC 브라우저)
교인 앱 (휴대폰)
입력한 이름·대표 색이 상태바·메뉴탭·공지띠·대표 카드·바로가기·설교·홈 화면 추가·탭바에 즉시 반영됩니다.
도입 혜택 — 교회 규모·상황에 맞춘 혜택은 상담 때 안내드립니다.
이런 고민, 이렇게 해결합니다
아래 카드를 누르면 데모 교회 교인 화면에서 실제 모습을 볼 수 있습니다.
주보, 매주 따로 올리기 번거로워요
주보 PDF를 한 번만 올리면 공개 홈페이지와 교인 앱 주보함에 동시에 반영됩니다.
설교 영상 정리가 손이 많이 가요
설교 YouTube 링크만 붙여넣으면 설교 다시보기 목록에 자동으로 정리됩니다.
앱을 꼭 만들어야 하나요?
앱 설치·심사 없이 '홈 화면에 추가'로 교인 휴대폰에 교회 앱 아이콘이 생깁니다.
관리자는 이렇게 올립니다
구매를 결정하는 분이 직접 보는 운영 화면입니다. 카드를 누르면 관리자 콘솔로 이동합니다.
주보 올리기
주보 목록에서 파일을 올리면 등록 창이 바로 열려, 한 화면에서 게시까지 끝납니다.
대시보드
교인 수·새 공지·설교·주보 현황을 한눈에 보고 다음 할 일로 바로 이동합니다.
기본으로 들어 있어요
아래 기능은 별도 추가 없이 기본 제공됩니다. 칩을 누르면 기능 소개로 이동합니다.
교회소개·연혁 예배·오시는길 설교 다시보기 주보 PDF 공지·상단고정 교회별 회원가입 알림·예약발송 로고·대표색 홈화면 스타일 교회 전용 주소 글자크기 조절 자체 도메인(옵션)
상품 · 혜택
WEB이 기본 상품이고, 전용 앱(APP)은 옵션입니다. 금액은 시장 검증 후 확정되며 현재는 미표시입니다.
기본
WEB
PC·모바일 웹 + 설치형 PWA. 교회 소개·설교·주보·공지·회원가입·관리자 콘솔·교회 전용 주소·웹 푸시 알림 포함.
 옵션
APP
iOS·Android 전용 앱 + 앱 푸시·딥링크·스토어 등록 대행. WEB 요금 + 앱 비용 별도(상담 후 견적).
요금 · 결제 안내
WEB — 초기 등록비 + 월 이용료금액 미표시
APP(옵션) — WEB 요금 + 앱 비용 별도상담 후 견적
결제 — CMS 출금이체(신청서 양식 다운로드)자동이체
자체 도메인 연결은 Premium 옵션이며, 앱 스토어 심사 일정은 보장되지 않습니다. 금액은 교회 확인 후 안내드립니다(현재 미표시).
