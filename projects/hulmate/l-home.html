교회마다 독립 Web·PWA를 설정만으로

별도 개발 없이 설정만으로 교회 공개홈과 교인용 PWA를 엽니다. 각 교회는 자체 브랜드의 독립 서비스처럼 운영되고, 교회 데이터는 서로 분리(테넌트 격리)됩니다. 교인은 교회를 검색하지 않고 전용 주소로 접속하면 소속 교회가 자동 지정됩니다.

핵심 가치

도입 교회가 얻는 세 가지. 카드를 누르면 기능 소개로 이동합니다.

독립 브랜드

교회 로고·색상·전용 주소로 독립 서비스처럼 보입니다. 훌메이트 플랫폼은 겉으로 드러나지 않습니다.
설정만으로 오픈

개설 신청 후 관리자 콘솔에서 설정만 하면 공개홈과 교인 PWA가 열립니다. church_id는 자동으로 부여됩니다.
Web Push 알림

공지·설교 소식을 Web Push로 알립니다. 네이티브 앱은 차기 과제(준비 중)이며, 현재는 Web·PWA 중심입니다.
서비스 채널

교회 공개홈·교인 PWA·관리자 콘솔을 하나의 디자인 시스템으로 제공합니다. 카드를 누르면 WEB 상품 소개로 이동합니다.
